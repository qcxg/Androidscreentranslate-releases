# Screen Translator Releases

Screen Translator 的官方二進位發布倉庫。這個倉庫只提供已簽章的 APK、版本資訊與檔案校驗值，不包含應用程式源碼。

## 下載最新版

- [Screen Translator 主程式](https://github.com/qcxg/Androidscreentranslate-releases/releases/latest/download/screen-translator.apk)
- [Hook 模組](https://github.com/qcxg/Androidscreentranslate-releases/releases/latest/download/screen-translator-hook.apk)
- [SHA-256 校驗值](https://github.com/qcxg/Androidscreentranslate-releases/releases/latest/download/SHA256SUMS.txt)
- [所有版本與更新說明](https://github.com/qcxg/Androidscreentranslate-releases/releases)

## 安裝需求

- Android 8.0 或以上版本
- OCR 與無障礙模式只需安裝主程式
- Hook 模式需另外安裝 Hook 模組，並使用相容的 LSPosed 環境設定作用域

Android 可能會提示 APK 來自瀏覽器或檔案管理器。安裝前請確認下載來源是本倉庫，並可使用 `SHA256SUMS.txt` 驗證檔案完整性。

## About this repository

This is the official binary distribution repository for Screen Translator. It contains signed APK releases, release notes, and checksums only. The application source code is maintained in a private repository and is not distributed here.
