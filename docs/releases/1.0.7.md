# Screen Translator 1.0.7

## 更新內容

- 主程式全面採用 Material 3 Expressive，支援系統取色、深淺色和自訂配色。
- 首頁三種顯示內容保持同級選項。來源及目標語言並排，並簡化 OCR 提示。
- 玻璃底欄使用單層外框，選取指示器加入彈簧回彈。快速設定的四個字幕開關採用平面排列。
- 翻譯服務改為分組列表，公開服務可直接啟停，私有服務的憑證編輯器在對應項目下展開。
- 主程式與 Hook 模組同步更新為 1.0.7（10007），沿用正式 Release 簽章。

## Changes

- Apply Material 3 Expressive across the main app, with system, light, dark, and custom colors.
- Keep all three display modes visible as peers. Place the language pickers side by side and simplify the OCR hint.
- Use one border around the floating navigation bar and spring motion for its indicator. Flatten the four subtitle switches in Quick Settings.
- Group translation providers into expressive lists and open private credentials directly below the corresponding provider.
- Update both APKs to 1.0.7 (10007) with the existing release certificate.
