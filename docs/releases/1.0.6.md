# Screen Translator 1.0.6

## 更新內容

- Hook 管理支援匯入可執行的第三方 JSON v2 適配規則：指定目標包名／程序、方法參數型別與字幕欄位路徑，無需重新編譯主程式。
- 無障礙支援頁新增第三方適配管理，可匯入、啟停、匯出與刪除節點規則，依包名、resource ID 及類別選取字幕。
- 同一 App 的內建與第三方 Hook 適配可獨立啟停；使用共用作用域時，不會因關閉其中一個適配而停用其餘來源。
- Hook 規則透過同簽章模組與框架 Remote Preferences 同步；來源驗證支援已啟用的第三方目標，並為各來源使用獨立的工作階段令牌。
- 主程式與 Hook 同步更新為 1.0.6（10006），沿用正式 Release 簽章。
- 公開下載倉庫同步完整中英雙語指南、適配規格、範例及更新後的技術文件。

## 使用與相容

匯入規則後請手動啟用。自訂 Hook 需要支援 libxposed API 102 與 Remote Preferences 的框架，完成作用域授權與規則同步後，完整重新啟動目標 App。無障礙規則變更立即更新服務；已發佈 1.0.5 的描述式 Hook 目錄仍可匯入，但要補上 v2 runtime 規則才能執行。

範例使用虛構包名，需修改為目標 App 的實際值。格式驗證通過不代表所有 App 版本皆相容。適配目錄需另外匯出，通用設定備份仍不包含適配目錄或框架作用域。

## Changes

- Import executable third-party Hook JSON v2 rules specifying the target package/process, exact method parameter types, and caption field paths without rebuilding the main app.
- Manage imported accessibility adapters: enable, disable, export, and remove node rules matching packages, resource IDs, and classes.
- Toggle built-in and third-party Hook adapters independently when they share an app and framework scope.
- Synchronize rules through the matching signed module and framework Remote Preferences; validate enabled custom sources and use independent session tokens per source.
- Update both APKs to 1.0.6 (10006), signed with the existing release certificate.
- Publish the complete bilingual guide, adapter specification, templates, and updated technical documentation in the public download repository.

## Usage and compatibility

Enable imported rules manually. Custom Hook rules require a framework supporting libxposed API 102 and Remote Preferences. Approve scope, synchronize rules, then fully restart the target app. Accessibility changes update the service immediately. Legacy descriptive Hook catalogs remain importable; add v2 runtime rules to make a custom adapter executable.

Templates use a fictional package and need real target values. Successful format validation does not guarantee compatibility with every app version. Export adapter catalogs separately; general configuration backups do not include adapter catalogs or framework scope.
