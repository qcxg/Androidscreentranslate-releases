# 權限與安全邊界

對應 1.0.6，核對日期為 2026-10-30，含第三方適配接口。本文記錄現行實作與限制，不是全平台安全認證或依賴漏洞掃描結果。

## 資料與權限

| 路徑 | 本機讀取內容 | 遠端傳送 |
| --- | --- | --- |
| OCR | 授權的 MediaProjection 圖片，本機 ML Kit 辨識 | 啟用翻譯時只送文字，不送圖片 |
| 無障礙 | 支援套件的可見原生字幕節點，工作階段內處理 | 啟用翻譯時送字幕文字 |
| Hook | 目標 App 的字幕與會話資訊 | 先送主程式，啟用翻譯後送文字至所選服務 |

錄製啟用時，原文及譯文寫入 App 私有儲存；手動匯出及備份會另外產生可分享文件。

浮窗需要 `SYSTEM_ALERT_WINDOW`，OCR 另需每次系統確認螢幕擷取授權。事件字幕不要求 MediaProjection。無障礙由 `BIND_ACCESSIBILITY_SERVICE` 管理，manifest 預設 YouTube，連線後依已啟用適配動態設定套件範圍，節點遍歷與文字均有上限。第三方 selector 決定提取範圍，過寬的規則可能選中一般介面文字。

無障礙支援頁可呼叫 `disableSelf()` 關閉服務；自動關閉選項在工作階段結束時執行，不在每次暫停時撤回。再次使用需重新授權。部分目標 App 會限制無障礙服務開啟時的使用，是否允許由目標 App 決定。

通知、前景服務及安裝模組所需權限由 manifest 宣告，管理入口集中在設定子頁。恢復設定備份不會授予系統敏感權限。

## Hook 通訊

字幕 Binder 服務接受以目標 App UID 執行的注入程式，因此沒有在該入口要求模組簽章。每次交易用 `Binder.getCallingUid()` 核對已啟用適配套件的安裝 UID，不信任 payload 自報 UID。若套件可見性令 getPackageUid 無法查到自訂目標，使用系統 AppOps 的 checkPackage 核對該 UID／包名配對，不要求列舉全部已安裝 App。

Android 14+ 廣播備援接受可信的系統 sender UID，或目前工作階段的隨機令牌。令牌為 32 個隨機 bytes，以 Base64 URL-safe 表示，只發送到支援套件。目標程序的動態接收器要求發送方持有 `SUBTITLE_BRIDGE` 簽章權限；工作階段結束後令牌失效，驗證使用常數時間比較。

`HookPluginRepository` 另核對協議、套件、已啟用可執行適配及 adapter ID、session、文字長度與遞增 sequence，並限制 session 數量。每個來源套件使用不同的隨機令牌，不能用一個目標的令牌冒充另一目標；停用的適配事件仍會被丟棄。擷取服務篩除工作階段之外、過舊及異常未來時間的事件。

框架狀態及作用域修改使用同簽章權限及 request ID。即使裝置允許不同簽章覆蓋安裝，主程式與模組仍可能無法正常進行這些通訊；正式發佈沿用 CI 的同一份 Release 金鑰。

UID 驗證無法區分同一 UID 內的原宿主與注入程式，框架與目標 App 是信任邊界的一部分。Hook v2 JSON 可選擇要觀察的方法與欄位；由已簽署模組解譯，不載入匯入的程式碼，不改寫原方法參數或結果，不呼叫任選 getter 或非文字物件的 toString。格式校驗、方法／欄位／文字與遍歷上限及來源授權仍會執行。v1 描述檔維持非執行語意，v2 checksum 並非作者身分證明。

## 網路、憑證與備份

網路設定禁止遠端明文 HTTP，只允許 `localhost` 與 `127.0.0.1`。OpenAI 相容 Provider 另驗證基底位址，拒絕含帳密、query 等不合規位址，並停用自動重新導向。

`SecureCredentialStore` 使用 Android Keystore 的 AES-256-GCM 金鑰加密私人 API 憑證。這保護本機儲存，不取代匯出密碼；無密碼備份仍含解密憑證，見[備份格式](backup-format.md)。

公共 Web Provider 使用非官方介面，其更新、限流、地區及服務政策可能影響可用性。使用者選擇的服務會收到翻譯文字，應自行確認其端點及資料處理方式。

系統雲端備份與裝置轉移已由 manifest 及 extraction rules 排除 App 資料，移轉使用手動備份。診斷記錄只包含狀態、來源、序號、長度或摘要指紋，不輸出字幕原文、API Key 或會話令牌。

## 發佈

金鑰、密碼與公開發佈權杖保存於私人倉庫 Actions Secrets，不寫入源碼。公開倉庫接收已簽署 APK、校驗檔、雙語指南、接口範例及明確選取的技術文件。公開文件同步使用固定檔案清單，不上傳應用程式源碼、建置設定或簽章資料；流程見[開發文件](development.md)。
